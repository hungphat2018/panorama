# 0002. Assemble existing tools before building new ones

- **Status:** Accepted — refined by [0006](0006-build-on-top-of-the-state-of-the-art.md)
- **Date:** 2026-10-10

## Context

The goal can be reached with a custom player or with a combination of existing tools. The real enemy is making the goal harder instead of achievable.

## Decision

Assembling existing tools is fine and encouraged. Custom work is for what existing tools cannot do.

## Consequences

- Most effort goes into choosing, configuring, and connecting tools, and into filling the gaps they leave.
- The project inherits those tools' limits, licenses, and release cycles.
