# 0006. Build on top of the state of the art

- **Status:** Accepted — refined by [0019](0019-settle-architecture-and-technology-first.md)
- **Date:** 2026-10-10
- **Refines:** [0002](0002-assemble-existing-tools-first.md)

## Context

Existing techniques each have their own weaknesses. Some technologies suggested early on may be outdated, or already improved upon elsewhere. Building on outdated foundations wastes time.

## Decision

- Build on top of the best available — the state of the art — to avoid spending unnecessary time.
- The project is not just a middleman using everything as given. It builds on top of existing techniques and breaks their weaknesses.
- Any recommendation of what to use or build on must be checked against the current state of the art first.

## Consequences

- Every technology choice needs a fresh state-of-the-art check before it is adopted.
